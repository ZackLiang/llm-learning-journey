# Agent Self-Evolution Reference Cards

This folder preserves preliminary research cards that informed the Agent Self-Evolution topic map.

They are intentionally excluded from the public MkDocs site because they have not yet reached the project's detailed paper-review standard: original-paper method verification, experiment setup extraction, figure/table interpretation, and evidence-boundary analysis.

Each card should be promoted back into `docs/paper-notes/agent-self-evolution/<topic>/` only after that full review is complete.
