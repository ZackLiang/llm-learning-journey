# LLM Learning Journey

Personal notes, implementations, projects, paper reading, and engineering exploration around large language models.

## Blog

[Open the learning blog](blog/index.html)

The blog is a lightweight static page. Open it directly or serve the repository with `python -m http.server 8000`, then visit `http://localhost:8000/blog/`.

## Repository Map

- `notes/`: theory and concept notes
- `implementations/`: small model components and mechanisms
- `projects/`: complete learning projects and reproductions
- `paper-notes/`: paper reading notes
- `engineering/`: inference, deployment, cost, and tooling
- `reflections/`: progress reviews and open questions
- `templates/`: reusable learning note templates
- `blog/`: visual static blog
