# 个人项目

本专题记录自己实际完成的实现、实验、工具和工程实践。与“前沿开源项目解读”不同，这里只收录自己亲自搭建、修改、运行或长期维护的项目。

## 内容范围

- **亲手实现**：为理解模型机制实现的最小组件、训练循环和实验代码。
- **工程记录**：部署、推理、算力、成本、工具链和故障排查。
- **完整项目**：有明确目标、代码结构、运行结果和复盘记录的个人实践。

## 当前入口

- [亲手实现](../implementations/index.md)：Attention、Transformer Block、LoRA、DPO/GRPO 等最小实现。
- [工程记录](../engineering/index.md)：推理、部署、成本、工具链和工程问题。

## 项目记录原则

每个正式项目尽量保留：

1. 项目目标与边界；
2. 系统结构与关键路径；
3. 环境、依赖和运行方式；
4. 结果、失败案例与改进过程；
5. 当前局限与下一步计划。
