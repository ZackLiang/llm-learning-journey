# Agentic RL Lab

[agentic-rl-lab](https://github.com/KMnO4-zx/agentic-rl-lab) 是我目前关注的一个学习型项目。它把大模型后训练、工具调用、Agent 环境和实验记录放在了一起。

## 我为什么关注它？

它有趣的地方不只是 GRPO、Search-R1 或 ReTool，而是把学习过程做成了可以逐步阅读的项目：

- 理论和训练循环放在一起；
- 记录了工具、环境和成本；
- 把失败、限制和实验不确定性写出来；
- 允许先用托管训练接口理解算法，再决定是否深入底层训练系统。

## PyTRIO

PyTRIO 是这个项目使用的托管训练接口。它把采样、前向反向和优化步骤封装到云端，让学习者可以把注意力放在 rollout、reward、loss 和环境交互上。

我目前更关心的问题是：哪些部分是平台封装的，哪些部分仍然需要自己理解，以及训练 reward、工具成功率和真实能力之间如何区分。
