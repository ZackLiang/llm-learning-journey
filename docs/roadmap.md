# Learning Map

这不是必须线性完成的课程，而是一张会随学习不断变化的地图。

## 01 · Model Internals

Tokenization → Embeddings → Attention → Transformer Block → Position Encoding → MoE → Sampling → KV Cache

## 02 · Training & Alignment

Pretraining → Data Quality → SFT → LoRA / QLoRA → Preference Optimization → Reward Modeling → RL / GRPO

## 03 · Evaluation

Benchmark Design → LLM-as-a-Judge → Data Contamination → Reward Hacking → Agent Evaluation

## 04 · Systems

Inference → Quantization → Batching → Serving → Cost Accounting → Reproducibility

## 05 · Applications

RAG → Tool Calling → Agents → Long Context → Multimodal → Agentic RL

## 记录状态

- **Reading**：正在阅读材料和源码
- **Thinking**：已经开始形成自己的解释
- **Building**：正在写代码或做项目
- **Published**：整理成可以回看的页面
- **Revisit**：之后需要重新验证
