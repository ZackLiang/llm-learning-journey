# 论文阅读

本专题用于记录大模型、Agent、训练方法和推理系统相关论文的系统性阅读过程。重点不在于复述摘要，而在于明确论文提出的问题、方法边界、实验依据、局限以及与已有工作的关系。

## 阅读框架

每篇论文解读尽量覆盖以下部分：

1. **研究问题**：论文试图解决什么问题，为什么现有方法不足。
2. **方法设计**：系统由哪些模块组成，关键假设是什么。
3. **实验设置**：模型、数据、任务、对照组和评测指标。
4. **实验结果**：表格与图中的数字分别代表什么，结果支持了哪些结论。
5. **证据边界**：论文没有证明什么，哪些结论依赖特定任务或实现条件。
6. **个人记录**：与已有知识的连接、仍需核对的问题和后续阅读方向。
