# EvoMemBench：Agent Memory 演化的系统评测

> 论文：**[EvoMemBench](https://arxiv.org/abs/2605.18421)**  
> 方向：Agent Memory 评测、时间尺度与记忆类型分解。

## 研究问题

Memory 方法仅报告最终任务分数时，难以判断提升来自：

```text
知识检索
执行经验复用
当前 episode 的更多上下文
跨 episode 的长期适应
```

EvoMemBench 因此提供两条分析轴：

| 维度 | 分类 |
| --- | --- |
| 时间尺度 | episode 内 / 跨 episode |
| 记忆类型 | 知识型 / 执行型 |

## 评测价值

该框架比较 15 种记忆方法和强长上下文基线，旨在回答不同记忆机制在哪类任务上真正有边际效用。

它提醒后续所有记忆演化论文：

```text
任务成功率上升
≠
记忆抽取、检索、使用和跨任务泛化都已被证明有效
```

## 阅读结论

EvoMemBench 不是自进化方法论文，但它为记忆自进化提供了必要的评测语言：必须分别讨论时间范围、记忆内容类型和行为影响。
