# Selection Is Not Learning：可学习任务不等于值得继承的更新

> 论文：**[Selection Is Not Learning](https://arxiv.org/abs/2610.22029)**  
> 方向：自生成任务、更新继承、独立评测选择。

## 研究问题

在 Self-Play 或自生成课程中，一个任务可能对当前模型“可学习”，但由该任务产生的更新不一定能改善外部能力。

```text
可学习
≠
值得继承
```

## 核心观点

若系统仅依据内部任务 reward 继承更新，可能产生：

```text
局部 reward 增长
课程内表现提升
外部 benchmark 无收益或退化
```

论文提出应使用新鲜、独立任务评估更新是否值得继承。

## 阅读结论

该工作将自进化中的关键问题从“如何产生更新”转向：

> 谁来决定一个更新可以成为下一代 Agent 的一部分？

这与 Validation/Test 分离、版本选择和回滚机制直接相关。
