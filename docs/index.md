## 这个网站记录什么？

这里不追求做成一套标准课程。每一篇内容都可以是：

- 一段对模型机制的重新解释；
- 一个从零实现的小组件；
- 一个开源项目的阅读和复现过程；
- 一篇论文带来的问题和判断；
- 一次部署、推理或训练中的踩坑。

## 学习方式

我更关注四个问题：

1. 我到底想理解什么？
2. 我是通过什么代码、论文或项目形成理解的？
3. 哪些地方已经能解释，哪些地方仍然模糊？
4. 下一步值得继续追什么？
